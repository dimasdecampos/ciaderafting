# Cia. de Rafting — rev3 ("rafting gourmet")

Visual requintado e executivo: verde-floresta quase preto, marfim e dourado champanhe, títulos em Cormorant Garamond e texto em Jost. As expedições aparecem como um "menu degustação", com ficha técnica e roteiro do dia.

Páginas: início, a casa (sobre), expedição 4 horas, expedição 6 horas e contato. Os links para trilhas, curso, equipe etc. levam às páginas da rev2.

- Gerador: `_src/build.py` (`pip install pillow`, depois `python _src/build.py` dentro desta pasta). Os textos ficam no próprio gerador.
- Para ver: `python -m http.server 8000` na pasta do projeto e abrir http://localhost:8000/rev3/
